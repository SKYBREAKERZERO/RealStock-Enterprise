可迁移

1.环境迁移 dev → staging → prod 使用Terraform

2.AWS Account 迁移 Account ID ; Subnet ID ; VPC ID ; Security Group ID ; ARN

3.Region 迁移 ap-northeast-1 → ap-southeast-1 可重建主要基础设施

4.应用迁移 通过 Adapter 层隔离AWS云专用服务 并保证应用自身:Docker FastAPI PostgreSQL Redis Rest OpenAPI 保持相对云无关
